Приговор на iPhone — как поставить
====================================

Нужно: iPhone с iOS 16.4 или новее, кабель, этот компьютер, бесплатный Apple ID.

ШАГ 1. Сборка (один раз завести GitHub)
  1. Зарегистрируйся на github.com (бесплатно).
  2. Создай пустой репозиторий: кнопка «New», имя prigovor-ios, Private, ничего не ставь галочками.
  3. Пришли Claude адрес репозитория (https://github.com/<твой-логин>/prigovor-ios).
     Claude отправит туда проект. Окно входа GitHub при первой отправке откроется само — войди.
  4. GitHub сам соберёт приложение на облачном Mac (5–10 минут):
     вкладка Actions → последний запуск «iOS build» → внизу Artifacts → Prigovor-ipa.
     Скачается zip, внутри Prigovor.ipa.

ШАГ 2. Установка на iPhone (Windows)
  1. Поставь iTunes и iCloud с сайта apple.com (не из Microsoft Store) — без них Windows не видит iPhone для установки.
  2. Поставь Sideloadly: sideloadly.io.
  3. Подключи iPhone кабелем, на телефоне нажми «Доверять этому компьютеру».
  4. Перетащи Prigovor.ipa в окно Sideloadly, введи свой Apple ID, нажми Start.
     (Пароль вводишь только ты, в самой программе.)
  5. На iPhone:
     • Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, телефон перезагрузится;
     • Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять.
  6. На экране появится значок «Приговор» с золотой лилией.

Важно про бесплатный Apple ID
  • Приложение работает 7 дней, потом его надо переподписать: снова Start в Sideloadly (сохранения не пропадут).
    Sideloadly умеет делать это сам по Wi-Fi, если включить в нём автообновление.
  • Для игры нужен интернет: движок three.js и шрифты грузятся из сети, как в APK.

Обновить игру

  дальше снова шаг 1.4 и Start в Sideloadly.
